# Graphosaurus: Grounded Knowledge Graph Reasoning

This system uses a **GraphRAG** (Graph Retrieval-Augmented Generation) architecture to answer natural language questions about paleontology using a Wikipedia-grounded Knowledge Graph.

## 🧠 System Architecture

1. **Natural Language Interface**: Users ask questions in plain English.
2. **Text-to-Cypher**: An LLM (Llama 3.3) uses the graph schema to generate precise FalkorDB queries.
3. **Structured Retrieval**: FalkorDB executes multi-hop traversals to find grounded facts.
4. **Grounded Synthesis**: The system generates a narrative response, citing Wikipedia sources retrieved from the graph nodes.

## 🦖 Design Decisions 

### 1. The Verification Gatekeeper
Instead of trusting LLM outputs blindly, this system uses a **Verification Loop**. Every dinosaur generated by the LLM must have a corresponding Wikipedia page. If it doesn't, the species is rejected to prevent hallucinations.

### 2. Temporal and Taxonomic Grounding
- **Float Conversion:** Geological ages (`start_ma`, `end_ma`) are stored as floats to allow for mathematical safety checks.
- **Strict Taxonomy:** Data is categorized by `Class` and `Clade` to allow the system to logically refute questions like "Which dinosaurs were mammals?"

### 3. Resilience to Naming Variance
The system uses `CONTAINS` in Cypher queries to handle the scientific specificity provided by Wikipedia (e.g., matching "Jurassic" within "Late Jurassic Period").

## 🛠️ Setup
1. **Docker**: `docker run -p 6379:6379 -p 3000:3000 -it --rm falkordb/falkordb` to spinup the FalkorDB docker image.
2. **Install the required packages**: `pip install -r requirements.txt`
3. **Environment**: `export GROQ_API_KEY='your_key'`
4. **Run**: `streamlit run src/app.py` and chat with the system!

## 🖥️ Web Interface
The project includes a **Streamlit** dashboard for an interactive GraphRAG experience.

- **Natural Language Chat**: Query the database using plain English.
- **Traceability**: All answers include direct Wikipedia citations pulled from node metadata.
- **Real-time Reasoning**: See the generated Cypher query in the backend while the assistant synthesizes the answer.

## 🛡️ Safety & Truthfulness
By leveraging a **GraphRAG** approach instead of a standard RAG (Vector only), this system maintains a "Source of Truth" in the graph structure, allowing it to mathematically verify dates and taxonomic classifications.
